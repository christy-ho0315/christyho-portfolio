# Christy Ho Portfolio

A complete React + TypeScript portfolio using the supplied photography, graphic design, and creative-technology work.

## Install in VS Code

1. Make a backup copy of your current website folder.
2. Keep your existing hidden `.git` folder. Do not delete it.
3. Unzip `Christy-Ho-Portfolio-Complete.zip`.
4. Copy everything inside the unzipped folder into the root of your existing website project. If VS Code asks, choose **Replace** for matching website files. This does not replace `.git` because the ZIP does not contain one.
5. Open the project folder in VS Code.
6. Open **Terminal → New Terminal**.
7. Run `npm install`.
8. Run `npm run dev`.
9. Open the local address shown in the terminal (usually `http://localhost:5173`).

For a final production check, run `npm run build`. The optimized production site will be created in `dist`.

## Pages

- Home: animated hero, floral mark, cursor photo trail, Polaroids, selected work, film strip, and About preview
- Photography: Digital and Film collections with complete galleries
- Graphic Design: numbered projects and complete detail galleries
- Tech / UI·UX: the Processing vinyl-cover project
- Contact: email, social links, portrait, and résumé
- Résumé: printable page and downloadable text version

## Notes

- All 92 supplied portfolio files are represented. PDF projects include optimized cover previews and links to the original PDFs.
- Images are resized for the web; the supplied source ZIP remains unchanged.
- Motion automatically reduces when a visitor enables “Reduce motion” in their device settings.
